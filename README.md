# React Components — Button / Input

## 📌 Опис проєкту

Навчальний React-проєкт для практики створення та використання компонентів із `props` та обробниками подій.

У проєкті реалізовано компонент, який приймає необхідні `props` та використовується в основному компоненті `App`.

### Реалізовано:

* створення окремого React-компонента;
* передача даних через `props`;
* обробка подій користувача;
* імпорт та використання компонента в `App.jsx`;
* перевірка роботи компонента в браузері.

## 🧩 Компонент

Компонент приймає такі `props`:

* `text` — текст, який відображається на кнопці;
* `type` — тип кнопки (`button`, `submit` тощо);
* `onClick` — обробник натискання на кнопку.

Компонент розташований у директорії:

```text
src/components/
```
